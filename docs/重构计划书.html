📋 项目背景

CviCubeMX 是一款芯片引脚配置工具，为 CV 系列芯片（cv1801c/h、cv1811c/h、cv1842cp/hp）提供引脚功能配置、外设管理、时钟树配置、内存布局、Flash 分区以及代码自动生成等一站式开发辅助能力。

当前技术栈

语言C++17
UI 框架Qt 6.x (Widgets)
构建系统CMake 3.16+
目标平台Windows / Linux
代码规模~12 个 .cpp + ~12 个 .h，ClockConfig 头文件 700+ 行

核心功能清单

  • 6 款芯片选型，QFN/BGA 双封装
  • 引脚功能可视化配置 (GPIO/ADC/I2C/UART/SPI/PWM/Timer)
  • 设备树 (DTS) 解析与外设管理
  • 时钟树 PLL 可视化与频点计算
  • 内存区域 & Flash 分区管理
  • CODE 生成 cvi_board_init.c
  • AI 对话助手 (HTTP SSE 流式)

🎯 重构动机

🔧 编译与依赖痛点

Qt 6.x + MSVC 工具链体积庞大（几 GB），windeployqt 部署流程繁琐，新开发者环境搭建门槛极高。每次发版需要手动打包 DLL。

📦 跨平台与分发

Linux 下需要额外安装 qt6-base-dev，无法做到"下载即用"。Tauri 生成的二进制体积小（~5MB），自带 WebView，不需要运行时依赖。

🧩 可维护性

C++/Qt 代码 UI 与逻辑强耦合，ClockConfig 单文件 700+ 行声明 + 数千行实现。TypeScript + React 组件化拆分，Rust 处理底层文件与计算逻辑，各司其职。

🚀 开发效率

热更新 (HMR) 前端秒级刷新，Rust 编译虽慢但只改后端时才触发。TypeScript 生态丰富（图表库、UI 库），可大幅加速时钟树可视化等复杂 UI 的开发。

🔲 M2 — 芯片选型与引脚视图

对应原 chipconfig.cpp/.h + pinwidget.cpp/.h + pinfunction.cpp/.h，是应用的核心交互界面。

前端设计要点

芯片选择流程

  1. 用户在 TopBar 下拉框选择芯片型号
  2. 前端调用 invoke("load_chip_spec", {chipType})
  3. Rust 返回 ChipSpec（封装类型、引脚数、布局参数）
  4. 根据封装类型渲染 QFN（四边方形）/ BGA（网格圆形）布局

QFN 布局渲染

使用 CSS Grid + 绝对定位，将 N 个方形 PinButton 分布在芯片四边（左→底→右→顶逆时针）。 每个按钮点击弹出 ContextMenu 选择功能，选中后变色。

BGA 布局渲染

使用 CSS Grid 渲染 N×N 网格（如 15×15），按行号 A-R（跳过 I）+ 列号 1-15 定位。 圆形按钮，悬浮时显示 PAD 名称 tooltip。

引脚搜索与闪烁

原 onSearchTextChanged + onBlinkTimeout 逻辑： 输入引脚号 → 滚动到该引脚 → CSS animation 闪烁高亮 3 次后常亮。

⏱️ M4 — 时钟树配置

对应原 clockconfig.cpp/.h，是整个项目中最复杂的模块（700+ 行头文件声明 + 数千行实现），包含 OSC→PLL→子PLL→输出节点的完整时钟树可视化、拖拽缩放、连接线绘制。

难点分析

  • 原 Qt 使用 paintEvent + QPainter 手绘连接线和箭头
  • ~20 个 PLL/子 PLL 区域，每个有独立的 divider/multiplier 控件
  • 拖拽和缩放模块位置（自定义 ResizeHandle 八个方向）
  • 左侧时钟树 QTreeWidget 导航 + 右侧 Canvas 流程布局
  • 搜索定位 + 高亮闪烁

方案 A：HTML5 Canvas（推荐）

技术选型

使用 React Flow 或 自研 Canvas 引擎 渲染节点图。 React Flow 自带节点拖拽、缩放、连线、MiniMap，但定制节点样式需额外开发。 若对性能和控制力要求极高，可用 Konva.js (Canvas 2D) 或 PixiJS (WebGL)。

原 Qt 特性React Flow / Konva 替代
PLL GroupBox + SpinBox自定义 Node 组件，内含 Input 控件
drawConnectionLines (手绘)React Flow Edge / Konva Line + Arrow
拖拽模块位置React Flow 内置 onNodeDrag
缩放手柄 (8方向 Resize)自定义 React Flow Node 的 resize handle
QTreeWidget 导航左侧 Tree 组件，点击 → setCenter(node)
搜索 + 定位 + 高亮filter → setCenter + className 切换动画

⚠️ 风险与对策

🔴 时钟树可视化难度

原 Qt 使用 QPainter 手绘，涉及拖拽、缩放、连接线等复杂交互。Canvas 方案需要大量自绘逻辑。

对策：优先评估 React Flow，若无法满足再使用 Konva.js 自研。Phase 3 预留 3 周缓冲。

🟡 DTS 文件格式保持

DTS 文件包含注释和特殊格式，解析-修改-写回必须保持非修改部分的原样。

对策：使用行级定位（记录 line_number），只做精确的字符串替换，而非完整 AST 序列化。

🟡 数据格式迁移
